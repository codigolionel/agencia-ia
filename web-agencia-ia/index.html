    glosario las palabras de esta guía

    Lo que significa cada cosa.

    Sin vueltas, como te lo explicaría en una llamada.

    API
    La puerta de servicio de un programa: tu sistema le manda algo a la IA y recibe la respuesta, sin que nadie escriba nada. Se paga por uso.
    Agente de IA
    Un sistema que atiende solo: lee el mensaje, entiende qué quiere y contesta con lo que sabe del negocio.
    Claude Code y Codex
    La IA que construye: le pedís algo en castellano y escribe el programa, con vos al lado.
    Servidor (VPS)
    Una computadora que no es tuya y no se apaga nunca. Ahí viven las aplicaciones y los agentes de tus clientes.
    Coolify
    El panel para manejar ese servidor, y para desplegar lo que armaste con Claude Code: subirlo para que ande.
    Chatwoot
    La bandeja de entrada del negocio: ahí quedan todas las conversaciones, para que las vea una persona. Es gratis y de código abierto.
    AgentKit
    El kit del agente, con Chatwoot y Coolify. Es gratis: pagás el servidor y el modelo.
    API oficial de Meta
    La forma de conectar WhatsApp sin techo y sin riesgo de perder el número. Desde el 1 de octubre de 2026 cobra por mensaje, pasados los mil gratis del mes.
    Triaje
    Un agente que entiende qué quiere cada mensaje y lo pasa al que sabe. Mejor que uno solo con todas las herramientas.
    RAG o base de conocimiento
    Que la IA busque en tus documentos antes de contestar. Treinta hojas no necesitan un RAG.
    Sistema operativo de IA
    Todo el negocio conectado, con su contexto: el dueño ve lo que pasa sin pedirle un reporte a nadie.
    Git y GitHub
    Donde vive el código. El de tus clientes va en su GitHub privado: es de ellos.
    Demo
    Algo chico que anda y le resuelve un dolor al rubro. Se usa para cerrar; no se regala.
    Ecuación del valor
    La de Hormozi: el resultado soñado por la probabilidad de lograrlo, dividido la demora por el esfuerzo.
    Visitas reales
    Las visualizaciones con interacción: la gente que se queda, no la que se va al segundo.
    Descremado
    El que quiere el material gratis o la plata fácil, y nada más. Siempre van a venir: no te frustres.
    Mes a mes
    El cliente paga el mes por adelantado y puede cortar avisando antes del siguiente. Se queda porque le sirve.
    Mapa
    Todo lo que se va a hacer, por escrito, antes de arrancar. Contra eso se mide lo prometido y lo cumplido.
